# 試玩評分表（fun rubric）

前面的驗證器和評審只回答「這份劇本跑不跑得動」。這一關問的是另一個問題：**四個玩家坐下來玩兩小時，會不會覺得好玩。**

你不是在校對格式。假設 JSON 已經完全合法，現在請你在腦中把它跑一遍：玩家進場、東看西看、跟 NPC 講話、卡住、找到線索、走向結局。然後誠實回答哪裡會冷場。

## 在腦中試玩的方法

從 opening_scene 開始，只用玩家看得到的東西推演（玩家看不到 full_story、看不到 gm_notes、看不到證物的 how）。每一步問自己：

1. 我現在知道可以做什麼嗎？
2. 我做了之後，有沒有拿到新的東西（線索、地點、NPC 態度改變）？
3. 如果我猜錯方向，還有別條路嗎？

## 評分項目（每項 1–5 分）

| aspect | 問的是什麼 | 1 分長怎樣 | 5 分長怎樣 |
|---|---|---|---|
| `開場鉤子` | 第一回合玩家知道要做什麼嗎 | 只描述氣氛，沒有可執行的動作 | 開場就指向一個具體的人或地點 |
| `線索鏈` | 線索是一條線還是有分支 | 卡住其中一步就完全前進不了 | 多條路通往同一個真相 |
| `卡關風險` | 玩家會不會不知道下一步 | 關鍵證物要玩家猜到特定動詞 | 每個地點都留下指向下一步的提示 |
| `NPC 深度` | 值不值得反覆盤問 | 一問就把知道的全講完 | 情報有條件、有立場、會隨進度改變 |
| `選擇的重量` | 不同結局差別大嗎 | 結局只差一句話 | 玩家的取捨真的改變了誰的下場 |
| `節奏` | 內容量配不配得上預估時長 | 五個地點但只有兩件事可做 | 探索、對抗、收尾的份量分配得開 |
| `恐怖感／氣氛` | 情緒有沒有往上堆 | 從頭到尾同一個強度 | 有鋪陳、有轉折、有失控的一刻 |

## 必修風險（risks）

只列**會讓某一場遊戲真的變難玩**的東西，每一條都要指出位置和具體改法。常見的有：

- 某條必要目標只有一種達成方式，而那個方式需要玩家講出特定句子。
- 某個地點玩家去了之後什麼都拿不到，也沒有指向別處。
- 所有 NPC 的情報都沒有條件，玩家第一輪就能把真相問完。
- 真相全部集中在最後一個地點，前面都是跑腿。
- 結局條件太嚴，正常玩法幾乎一定落到同一個結局。
- 沒有任何時間壓力或威脅，玩家可以無限嘗試。

不要列「再多寫一點描述會更好」這種話。

## 輸出格式

只輸出一個 JSON 物件，不要任何說明文字，不要用 ``` 包起來：

{
  "verdict": "值得試玩",
  "one_line": "一句話說這場玩起來像什麼",
  "ratings": [
    { "aspect": "開場鉤子", "score": 4, "why": "開場把玩家放在旅館並點名莉莉安，第一步很明確。" }
  ],
  "risks": [
    { "where": "objectives[3]", "issue": "砸毀祭壇需要鐵鎚，但沒有任何地點給得到。", "fix": "在燈塔的工具箱放一件鐵鎚證物。" }
  ],
  "highlights": ["葛莉塔要先請酒才開口，這個小門檻讓旅館值得回頭。"]
}

- `verdict` 只能是「值得試玩」「需要調整」「會卡住」三者之一。
- `ratings` 七項都要給，順序照上表。
- `risks` 最多 6 條，沒有就給空陣列。
- `highlights` 最多 3 條，寫這份劇本真正做得好的地方。
