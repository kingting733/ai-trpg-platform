# 解剖卡

格式見 `../autopsy-template.md`。整理後的手法在 `../story-craft.md`。

**卡片本身不放在這裡。** 參考故事是使用者購買的作品，部分作者聲明「勿營利」「勿改編後發布」，而這個倉庫是公開的。所以完整的解剖卡和原文只存在本機：

- 原文：`stories/source/<編號>/`
- 解剖卡：`stories/source/autopsies/`

兩者都被 `.gitignore` 排除。雲端環境重開後會消失；需要時請使用者重新上傳原文，再重做卡片。
