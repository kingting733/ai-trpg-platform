# 好的克蘇魯故事長什麼樣（初稿）

> **狀態：初稿。** 這一版是從跑團設計的通則寫的，還沒對照那十篇故事。十張解剖卡填完後，用它們**驗證、修正、換掉**這裡的每一條——留下來的每條都要能指出「哪幾篇這樣做、效果如何」。對不上的就刪。

寫法刻意白話，可以直接摘給創作者看。每條都附「為什麼」，因為平台的限制和桌上跑團不同，照抄桌上經驗會踩坑。

## 1. 先決定「真相」，再決定「表面」

玩家看到的永遠是表面：一樁失蹤、一間鬧鬼的公寓、一個守則怪怪的大樓。真相藏在底下，而且通常有三層——

1. **表面事件**：發生了什麼（有人失蹤、有人死了）
2. **人為掩蓋**：誰在隱瞞、為什麼（鎮長、管理員、家人）
3. **神話真相**：底下那個不屬於人間的東西

好故事讓玩家一層一層剝；每一層都有自己的證據、自己的「原來如此」。只有一層的故事（直接撞見怪物）沒有調查可言；只有人為那層的故事是推理劇不是克蘇魯。

為什麼要分層：平台上每一層都對應到不同的證物與 NPC 情報，分層清楚，線索網才排得出來。

## 2. 鉤子 = 一個人 + 一個請求 + 一個期限

第一回合玩家就要知道該找誰、去哪。最穩的寫法：有一個具體的人（莉莉安、陳婆婆、管理處主任）提出具體的請求（找到我未婚夫、搬進去前查清楚這間房），而且有壓力（三天後、天亮前、下一次漲潮）。

- ✗ 只鋪氣氛：「你們來到了霧氣瀰漫的小鎮……」——玩家不知道第一步做什麼。
- ✓ 「莉莉安在旅館等你們，她說鎮長在說謊，燈塔已經三週沒亮。」

為什麼：平台一回合只有一個行動，四人團每人 7–8 回合。開場浪費兩回合摸索，整場就少了四分之一。

## 3. 線索要分三路

每個關鍵真相至少三條路拿得到：一個地點的物件、一位 NPC 的話、另一個地點或另一位 NPC。玩家漏掉一條、骰子失敗一次，不會卡死。

常見的三路組合：
- **文件**（日誌、信、帳本）＋**人**（會在某條件下開口的 NPC）＋**現場**（痕跡、符號、物品擺放）
- 三路可以互相指：日誌提到岩洞，老闆娘提到二十年前的守夜人，燈塔的粉筆記號指向暗門——三條都通往同一個地方。

為什麼：平台上拿證物要擲骰，失敗是常態。只有一條路的真相，等於把整場押在一次骰子上。

## 4. 恐怖要升溫，不要一開始就最大

四階：
1. **違和**——東西的位置不對、氣味、聲音、數字對不上。還沒有任何超自然證據。
2. **目擊**——看到了：影子、屍體、符號、不該在那裡的人。
3. **接觸**——它注意到你了：被跟蹤、被觸碰、NPC 突然不正常。
4. **不可理解**——揭露，而且揭露本身就是傷害：儀式、邪神、異界。

每一階都要有**畫面**，因為平台的理智檢定靠 AI 敘述裡的畫面觸發（屍體、觸手、祭品……）。一開場就「邪神降臨」，後面沒東西可升，理智也早早扣光。

分配：前三分之一回合只給違和與一次目擊；中段目擊與接觸；最後三分之一才不可理解。

## 5. 每個 NPC 都要有「想要／隱瞞／謊言」

沒有立場的 NPC 是會說話的告示牌，一問就把知道的全講完。給每位：
- **想要什麼**：保護女兒、保住工作、讓祭壇「吃飽」
- **隱瞞什麼**：他知道但不會主動說的
- **說了什麼謊**：他主動說的假話——玩家發現謊言的那一刻，比發現真相還刺激
- **在什麼條件下會改變**：拿日誌對質才崩潰；喊出莉莉安的名字才清醒；第 N 回合後態度轉硬

至少一條情報要有條件。而且 NPC 要有**位置**——他在旅館、在鎮公所、第五回合後在碼頭；平台靠這個決定玩家在哪裡遇得到他。

## 6. 地點要有事可做，而且互相指向

每個地點進去都要能拿到東西（證物或情報），或至少留下指向下一步的提示。地點之間要互相指：旅館的八卦指向鎮公所，鎮公所的日誌指向燈塔。

地點不是越多越好。5–12 個，每個都有用，比 20 個空房間好玩。

鎖與隱藏要有道理：燈塔鎖著是因為鑰匙在鎮長身上（拿到鑰匙證物才開）；岩洞隱藏是因為要先到燈塔才發現暗門。

## 7. 要有時鐘

某個東西在回合數上逼近：漲潮、天亮、下一次儀式、房東回來。沒有時鐘，玩家會把每個地點搜十次，故事沒有張力。

平台支援「到第 N 回合」「進入某地後過 N 回合」當條件，時鐘可以真的觸發事件（NPC 出場、地點變化、失敗結局）。

## 8. 目標是事件，結局是取捨

目標寫「會發生的畫面」：交出鑰匙、砸毀祭壇、把名單拿到手。不寫「理解」「決定」「合作」。

結局 2–4 個，要靠**玩家的取捨**分開，不是靠運氣：
- 救了人但沒毀祭壇 → 中性（總會有下一個守夜人）
- 毀了祭壇但人沒救到 → 另一種代價
- 都做到 → 好結局，但通常也付出了什麼（理智、同伴、真相公開的後果）
- 時鐘到了什麼都沒做 → 失敗

克蘇魯的好結局很少是「全贏」。活下來、封印、付出代價，才是這個類型的味道。

## 9. 失敗不是陷阱

玩家做了會失敗的事（吃下那塊糕、唸出那段咒文），要在故事裡**先給過警告**（守則第三條、NPC 的欲言又止、一次目擊），而且在失敗前至少有一次檢定或一次反悔的機會。直接即死的設計在桌上靠主持人緩衝，在平台上沒有人緩衝。

也絕對不要把這種動作列進任務目標清單——那是對玩家下套。
