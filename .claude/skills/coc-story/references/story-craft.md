# 好故事怎麼寫——從五篇參考故事整理

這份是 skill 的核心：寫新故事時，照這裡的手法設計，再用 `engine-constraints.md` 的檢查表把關。寫法刻意白話，可以直接摘給創作者看。

**依據**：使用者指定的五篇參考故事，每篇都做過完整解剖（真相分層、地圖、線索網、NPC、升溫、時鐘、結局、放進引擎會壞的地方）。每條手法後面的〔〕是出處：

| 代號 | 故事 | 類型 |
|---|---|---|
| 〔賃貸〕 | 賃貸物件（inSANe 規則） | 現代凶宅、都市怪談，兩條路線 |
| 〔活神〕 | 活神之手 | 詛咒物＋追獵者，單人、一天之內 |
| 〔分解器〕 | 分解器 | 封閉海濱旅館、多方爭奪神器 |
| 〔黑水溪〕 | 黑水溪 | 鄉村污染、溯源、大規模沙盒 |
| 〔華富邨〕 | 華富邨怪奇物語 | 香港屋邨、逃出鬼屋、中式民俗 |

解剖卡本身只存在本機（`stories/source/autopsies/`，不進 git：原作有「勿營利／勿改編發布」等聲明）。這份只寫手法，不寫原作的劇情細節；**新故事一律原創，不要改編這五篇**。

平台網站上現有的劇本不是範本，不要從它們取例子。

## 一、先選骨架：四種地圖

五篇裡做得最好的，都是先找到一條「載體」，再沿著它排地點。載體決定了地點的順序，也就讓「跟著線索走」和「恐怖越來越重」變成同一件事。寫新故事時，先從下面四種挑一種，再往裡面填東西。

### 1. 往源頭走的梯度〔黑水溪〕
所有地點沿著一條會流動、會擴散的東西排開（溪水、水管、通風管、電線、送貨路線、謠言），離源頭越近，異常越重：最外圈只有氣味和病，中段有變異的人和動物，靠近源頭是活的怪物，源頭是神。
- **為什麼好**：玩家漏掉任何支線都不會卡死，因為載體本身會把人帶到源頭；升溫不用另外設計。
- **平台寫法**：每一站的解鎖條件是「去過上一站」或「拿到上一站的證物」；證物描述隨距離加重，依序對上理智關鍵字的明顯、強烈、核心三級。通往源頭的最後一站，用「累積 N 件帶『源頭』標籤的證物」開門，標籤證物分散在 4–5 個地點。

### 2. 經手人鏈〔活神之手〕
一件詛咒物的經手履歷就是地圖：源頭 → A → B → C → 玩家。每位經手人一個地點，地點裡固定兩樣東西：一具屍體（證明威脅是真的）和一件指向上一任的物件（紙條、地圖、地址）。越往源頭死得越久。
- **為什麼好**：玩家往回查，威脅往前追，兩條線交會就是高潮。換成凶宅、詛咒錄影帶、遺物都能照做。
- **平台寫法**：地點用「拿到證物 X」串成鏈；屍體做成證物（只寫所見：腐爛程度、姿勢）；源頭地點放解法的線索。

### 3. 熟悉建築的異界複本〔華富邨〕
先讓玩家在一棟熟悉的建築（屋邨、商場、學校）的正常版逛 2–3 個地點，再把他們丟進同一棟樓的劣化複本。複本用玩家看得懂的障礙（塌方、積水）把環形走廊切成單行道，讓終點在第一眼就看得到、卻要繞一大圈。正常版見過的物件，在複本裡以恐怖的樣子再出現。
- **為什麼好**：熟悉感讓玩家腦中自帶地圖；「看得到走不到」本身就是張力；序章的探索在後段有回報。
- **平台寫法**：兩個區域，現實區只有一個入口通往異界區；兩區同名地點、同標籤證物；異界最後一扇門用「累積 N 件同標籤證物」開。地點只能打開不能再鎖，所以單行道靠「後面沒有要回頭拿的東西」成立，不靠真的鎖。

### 4. 公開日程表〔分解器〕
寫 4–6 個有固定時間的公開聚會（演示、晚宴、兩輪開標；換成婚禮、喪禮、股東會、通靈會都行），做成玩家拿得到的行程表。所有 NPC 在整點聚到同一處；每個整點夾帶一件恐怖事件，而且每件都給玩家一個離開這個房間的理由，一步步把人從燈火通明的室內拉進黑暗。
- **為什麼好**：玩家永遠知道下一件事是什麼，可以自己安排空檔；主持人永遠知道玩家什麼都不做時會發生什麼。
- **平台寫法**：開場就給證物「日程表」，寫明每個行程在第幾回合、在哪裡；行程地點用「到第 N 回合」解鎖；NPC 位置排成「第 N 回合後移到宴會廳」；恐怖事件做成綁地點的出場事件。**注意**：玩家不在場，行程對引擎等於沒發生，所以行程裡給的關鍵情報，一定要在別處另有一條路。

### 四種都適用的
- **地點 5–12 個，每個都要有事做**。五篇原作的地點數從 3 到 30 都有，空地點全是問題：只當佈景的房間、只扣理智的角落、畫在地圖上卻沒寫內容的建築。不是放東西，就是刪掉。
- **只有一個起點**。原作常有序章加正篇、或一開場九個地點全開；平台上只留一個開場地點，序章壓成開場敘述加起始證物。

## 二、真相與鉤子

### 真相分三層
五篇全部都是三層：**表面事件**（失蹤、意外、怪病）→ **人為掩蓋**（誰在隱瞞、為什麼）→ **神話真相**。每一層都有自己的證據。人為那層的掩蓋者，常常自己也是受害者或也被騙了〔活神：連史書都站錯邊〕。

### 鉤子＝反派掩蓋行為的副作用〔賃貸〕
先寫真相，再站在反派的位置問：「他此刻為了掩蓋，會做什麼在受害者看來莫名其妙的事？」把那件事原封不動交給玩家當開場。例：一向和善的房東突然無故拒絕續約。真相揭曉後，那件最不合理的事變成唯一合理的事。

### 官方說法 vs 真相〔華富邨〕〔活神〕
開場給玩家一份「官方版本」：剪報、廣播、警方說法、三件都能用常理解釋的意外。整場遊戲就是在挖官方版本底下的東西。

### 鉤子不一定要委託人
五篇裡三篇有委託人（同事寄來東西、教授拍電報、系主任請託），兩篇沒有，用日常壓力（租約到期、暴雨被困）。共同點是**第一回合就有一個具體的下一步**：一個人名、一個地址、一扇要敲的門。開場只鋪氣氛、沒有下一步的，是唯一一篇開場評分低的〔華富邨序章〕。

### 隱藏的期限
壓力可以一開始就說（拍賣只有今晚），也可以藏起來、靠接連傳來的消息揭開〔活神：死訊一個接一個，天黑時追獵者才會來〕。藏起來的期限要在故事前半給至少一次暗示，否則玩家感受不到壓力。

## 三、線索

### 決定勝負的那條知識，至少三個來源
**這是五篇共同最大的失敗**：每一篇都有一個「看不懂、沒拿到就輸」的單點——唯一寫著解法的日記壓在一次力量檢定下〔活神〕、唯一的終局炸藥只靠一次偵查〔黑水溪〕、唯一的逃脫方法是一張看圖謎題〔華富邨〕、魔王的弱點零條線索〔分解器〕、最關鍵的揭露只靠一次擲得夠高〔賃貸〕。
- 解法與終局工具，至少三個來源：一件文件、一位 NPC 在條件下說出、一個現場物件或夢境。**其中至少一條不需要檢定**。
- 檢定只決定「多花幾回合」，不決定「有沒有」。

### 失敗換時間，不換線索〔活神〕
原作規定：搜查失敗只要多花一倍時間就自動拿到。玩家永遠不會卡死，但每次失敗都看得到代價。
- **平台寫法**：同一份內容在第二個地方再放一次，用「進入該地點後過 2 回合」開一個子地點（例如「書桌底下」），裡面放同內容的證物。

### 慢路徑晚開門〔活神〕
主線斷了的隊伍，還有一條替代路線，但要等到後半場才開。用時間懲罰失敗，而不是用卡關懲罰。
- **平台寫法**：替代地點用「到第 N 回合」解鎖；兩條路的證物貼同一個標籤，下一站用「累積 1 件該標籤」開，兩條路都通。

### 謎題只能確認，不能是門〔華富邨〕
看圖謎題、密碼、回旋文在 AI 主持下只會變成「直接說破」或「說不清楚」。謎題可以留著當氣氛，但答案要另外由 NPC 和現場物件各暗示一次，而且任何一條都足以讓玩家知道該做什麼。

### 標籤累積開門
五篇裡四篇都有現成的「集滿幾件才開」結構：源頭證物〔黑水溪〕、同樣的刀口〔分解器〕、同一個窗景〔賃貸〕、紙紮物件〔華富邨〕。這是平台最好用的工具：一扇門不綁死在單一證物上，玩家走哪條路都湊得滿。門檻要夠高，不要讓最早的兩個地點就湊齊。

### 先懷疑人，再見鬼〔分解器〕
失蹤者的房間門反鎖、窗戶大開，看起來像人為；旁邊正好有一個被寫得很可疑的人類 NPC。答案在另一具屍體上同樣整齊的切口——兇手在屋外。兩件證物貼同一標籤，集滿才開出真正的現場。

### 每次理智檢定都要給東西〔華富邨反例〕
只為扣理智而存在的場景（作者自己說是拖時間的屍布角落）是冷場。每一個恐怖畫面都要同時給玩家一件證物、一個新地點，或一條 NPC 情報。

### 不要讓玩家猜動作
「搬開旁邊那塊大石頭」「說出那本禁書的書名」「把坑重新挖開」「先把引信烘乾」——原作裡這些都靠玩家自己想到。平台上，證物的「要做什麼」寫成玩家會打出來的動詞短語，而且現場描述要有東西指向它（石頭下壓著一角油布）。

## 四、NPC

### 數量：2–6 位，每位不可取代
原作的 NPC 從 3 位到 20 多位都有。人多的那幾篇，原作自己都說「用不到的就淡化」〔分解器〕〔黑水溪〕。規則：每位 NPC 要嘛擁有一條別人沒有的情報，要嘛在盟友光譜上佔一個別人沒有的位置；兩樣都和別人重疊，就合併。隨從、打手、員工只寫在描述裡，不建成 NPC。

### 每位一個社交把手〔分解器〕
司機吃「陪他喝酒」、妻子吃「之前對她有禮」、投機客吃「生存算計」、膽小的專家吃「溫和安撫」、主辦人吃「貪婪」。玩家有明確的施力點，社交戲就不是碰運氣。
- **平台寫法**：條件情報，條件寫成具體的證物或事件（「出示介紹信」「拿到 X 之後」），不要寫「如果玩家很有禮貌」。

### 事件前、事件後兩種狀態〔分解器〕
每位 NPC 綁一個公開事件當轉折點：專家從「這是騙局」變成恐懼、主辦人從不屑變成崩潰、賣家從推託變成良心不安。整群排成終局的盟友光譜，前半的社交選擇決定後半誰站在玩家這邊。
- **平台寫法**：態度不會換邊，所以轉折用「到第 N 回合／拿到某物之後」的條件情報表現；「誰站在玩家這邊」用結局條件（誰活著）收尾。

### 給的情報是真的，動機是假的
- **借刀殺人的盟友反派**〔黑水溪〕：他一開始有問必答，給的對手情報全部屬實，目的是讓玩家去消滅他的對手。玩家一拿到通往真正源頭的關鍵證物，他就移到源頭門口擋路。
- **部分真相讓反派收買你**〔賃貸〕：同一個揭露拆成兩層證物。只拿到第一層時，反派的說法剛好說得通，還開出誘人的條件；拿出第二層才崩潰。玩家沒查完不會卡關，而是走進一個看起來合理、其實錯誤的結局。

### 恐怖的載體先當普通人〔分解器〕〔華富邨〕
門童在前半幫每個人提過行李，後半才在霧裡用死人的嘴說話；邀大家玩遊戲的同學，沒人記得他是誰。熟人變了，比陌生怪物可怕。
- **平台寫法**：NPC 位置排成「先在大堂 → 第 N 回合後移到車道」；第 N 回合前的情報只聊日常。

### 會說謊、會自己走掉的人質〔黑水溪〕
救出來的人不一定可信，他真正想要的是回到怪物身邊。救了他，他就自己往終局地點走。
- **平台寫法**：NPC 移動條件「完成『解開他的鐵鍊』後移到終局地點」；被問到關鍵時先說謊，拿證物對質才承認。

### 不能對話的人，做成證物〔活神〕
只在電話那頭、已經死了、玩家趕到時剛斷氣的人，不建成 NPC。做成起點的證物：「打電話給某人」（只寫聽到的：響很久、聲音太冷靜）。這樣不會出現「到處都在的分身」，也不會出現「該死卻還活著」。

### 追獵者只在遠處被看見〔活神〕〔賃貸〕
白天的目擊是畫面（巷口、山坡、窗外的人影），永遠接近不了；本體只在入夜時登場一次，而且直接找上落單的人。
- **平台寫法**：目擊寫進地點描述或證物；本體是敵對 NPC，只靠一次出場事件登場（條件：到第 N 回合）。出場事件會把他移到觸發者身邊，分頭行動時就是單挑。

## 五、恐怖

### 違和＝日常的東西放錯時間和地點
不是拜神的日子卻飄著線香、整層樓沒有活人〔華富邨〕；家裡淡淡的酸臭、室友提著裝死金魚的濕垃圾袋〔賃貸〕；溪水和酒有同一股腐果味〔黑水溪〕。第一階恐怖不需要任何怪事。

### 升溫靠「距離」
- 空間的距離：越往上游越嚴重〔黑水溪〕。
- 死亡的距離：聽說 → 看到新屍 → 看到腐屍 → 三百年的白骨 → 會走路的死屍〔活神〕。
- 同一個意象的距離：每間房子的窗外都是同一個景，人影從鐵門內 → 鐵門前 → 你的窗下 → 貼在玻璃上〔賃貸〕。「不同地方看到一樣的東西」本身就是線索：問題不在房子，在你身上。
- 平台的理智檢定靠敘述裡的字觸發，所以**重複出現的畫面用違和級的字寫**（目光、人影、想不起長相），強烈與核心級的字留到後段。不要在中點就用到和終局一樣重的畫面〔華富邨反例〕。

### 先給甜頭的詛咒〔黑水溪〕
擴散的恐怖先有看得見的好處：病好了、眼睛亮了、傷口癒合、大豐收。這一招同時解釋了鎮民為什麼不逃、NPC 為什麼隱瞞、玩家為什麼想碰。至少讓一位友善 NPC 正在享受它。

### 一個母題貫穿〔活神〕
詛咒的副作用、惡夢、原典講的是同一件事（面具）。每一個怪事都在加強同一個意象，比十種不同的怪事更可怕。

### 把熟悉的東西翻過來〔華富邨〕
- 擋煞的八卦其實是困住救援的封印，拿下它是加分選擇。
- 可怕的鬼差其實是被擋在外面的幫手，手上還拿著鑰匙。
- 觀眾心中「抓殭屍的好人道長」原型，翻成養屍的兇手。玩家先入為主的信任本身就是陷阱。

### 讓現場自己演出〔華富邨〕
撿起受害者的遺物，現場重演當年的事，不需要 NPC 自白就把真相交給玩家。**只演事後痕跡**（腳印、拖痕、空床），不演暴力過程。

## 六、時鐘

### 把「看情況」全部換成條件
五篇原作都有大量「主持人覺得可以了」：局勢危急時才坦白、拖太久才出面、玩家卡住就丟一個事件、高潮隨時可以發生。**AI 主持人不會照這種軟性提醒走**，結果不是「第一次骰成功就全給」，就是「永遠不發生」。每一個會改變局勢的時間點，寫成：到第 N 回合、去過某地、拿到某證物、進入某地後過 N 回合。

### 時刻換成回合〔活神〕
原作用時刻推進（十點半廣播、傍晚五點開門、天黑時來訪）的，照這三條換：
1. **時間成本換回合成本**：「開車一小時」放一個真的過場地點，讓移動多花一步；不要靠敘述說「開了一小時」，系統不會記。
2. **時刻門檻換「到第 N 回合」**：傍晚才開的地方，第 N 回合解鎖。
3. **天黑換出場事件**：天黑才來的東西，做成「到第 N 回合」的出場事件。

天色（上午、午後、黃昏、入夜）可以讓 AI 依回合描寫，但那只是氛圍，不是規則。

**回合怎麼算**：一回合是每位玩家各行動一次。排時鐘時用「每位玩家有幾個行動」想：第 10 回合＝每人已行動約 10 次。

### 世界不等玩家，但引擎看不到沒人的地方〔分解器〕
原作「玩家錯過演示，時間線照走」。平台上沒有玩家在場的事件等於沒發生，所以：預定事件做成「第 N 回合解鎖的地點＋綁在那裡的出場事件」，事件裡給的關鍵情報，另外要有一條路。

### 回合上限當最後一道鐘
每篇都需要一個「到這裡就結束」：天亮、儀式完成、幼崽出生、大樓崩塌。寫成「到第 N 回合」的失敗結局，結尾畫面自己寫。

## 七、中點與高潮

### 落單者帶鑰匙回來〔華富邨〕
中點拆出一個人，他獨自面對全篇最可怕的東西，卻因此拿到唯一的解謎物，最後在決戰門口和大家會合。最慘的人變成救大家的人。
- **平台寫法**：引擎不能強迫誰落單，所以做成**自願**下去的隱藏地點（解鎖：去過某處），決勝物件放在那裡；終局地點的解鎖不要只綁這件物件，另給一條「去過某處後 N 回合」的路。

### 讓解法的規則自動排好高潮〔賃貸〕
解法規定「施咒的人和那扇窗必須同在一房才能解」，於是玩家想徹底解決，就必須把那個人帶到那個房間。決戰的地點和在場的人，由道具規則決定，不需要主持人安排。
- **平台寫法**：證物的所見寫明解除條件與步驟；相關 NPC 用出場事件（綁那個地點）帶到現場；勝利＝完成那個多步驟目標。

### 安全的半套解 vs 危險的全套解〔黑水溪〕
終局同時擺兩個動作：一個零風險但只是重蹈前人覆轍（封住洞口），一個要拚逃生但真正解決（炸掉源頭）。前人做過半套解的紀錄，要提早放進歷史證物，讓玩家有機會看出來。兩個動作用不同的物件區分，不要只差在地點。

### 解法是一種代價〔活神〕
真正的解法要玩家付出自己的東西（身體的一部分、名字、記憶），而源頭現場早就埋好視覺預告（骸骨缺了三根手指）。顯而易見的解法（丟掉、轉手、硬打）只能部分有效，落在中性結局，玩家才會覺得真正的解法是自己掙來的。代價大小可以由玩家的恐懼決定：一撮頭髮就夠，但沒人告訴他們。

### 有限度的逃生倒數〔黑水溪〕
點燃之後才開出逃生用的地點，一進去就開始倒數，必須在限定回合內完成多步驟的逃出目標：先完成觸發勝利，先到時觸發失敗。回合是全員各行動一次，所以 2–3 回合就是每人 2–3 個行動，夠緊張。

### 戰鬥是談判失敗的後果〔黑水溪〕
戰鬥前一定先有社交關卡；敵人分批到場，給玩家「人還沒到齊，先撤」的空檔；打不贏的敵人（不斷回血、槍打不動）逼玩家去找別的解法。

## 八、結局

### 三種玩家風格，三種結局〔活神〕
理解了規則的人（交還）→ 勝利；硬打的人（殺掉容器）→ 中性；拖到時鐘的人 → 失敗。玩家的風格決定結局，不是運氣。

### 用同一種文體當書擋〔華富邨〕
開場用一則舊案剪報講「別人」的事；結局用同一種媒體（電視新聞）講「玩家」的事，所有結局套同一個模板，只換關鍵句（找到了／沒找到／找到了但什麼都不記得）。玩家聽到結尾就懂：自己差一點成為開場那則新聞的下一個。

### 委託做成功，不能是壞結局〔黑水溪反例〕〔分解器反例〕
一篇的開場委託是「說服私酒商改供貨」，而私酒正是在擴散瘟疫：委託做得越好，世界越慘。另一篇叫玩家「最多出 6000 買下」，場上出價卻是 25,000。照目標做反而輸，在平台上就是陷阱。想要反諷，放在中性結局的收場白，不要放在目標上。

### 勝利條件要能執行〔分解器反例〕
「處理掉神器」是唯一的勝利，但神器打不壞，原作也沒說怎麼辦。勝利條件寫成「在哪個地點、用哪個物件、做哪個動作」。

### 看起來像死、其實是解答〔華富邨〕
「毀掉寫著自己生辰八字的木人」敘述起來像自殺，其實是逃出的方法。這種設計很好，但要寫白：證物、NPC 情報都要清楚指向它，結局觸發後第一句就寫「醒來」，否則玩家不敢做、AI 也可能寫成死亡。

### 每個結局都要寫死下場
原作常用「主持人和玩家商量」「擲壞結局表」收尾〔賃貸〕。平台上每個結局的「之後發生什麼、每個角色的下場」都要預先寫好。

## 九、改編現成模組時

如果使用者要把買來或寫好的模組搬上平台（先確認原作授權；作者不允許的不做），這是轉換清單：

- **只留一個開場**。兩套開場、序章加正篇、五種導入過場，全部壓成一個起點，序章給的線索搬進地圖。
- **砍佈景**：沒事做的地點、隨機表（三選一的資料合併成一件證物）、只為扣理智的場景。
- **合併 NPC**：隨從、打手、員工併進描述；NPC 留 2–6 位。
- **單人改多人**：單人模組的孤立感，改成「整隊和外界隔絕」（電話不通、警察不信）；內容量要放大，原作只有 5 個調查行動的，4 人團要好幾倍的證物。
- **規則換成平台有的**：理智點數扣時間、腐化階段、狂氣卡、儀式表、達成值分級、追逐規則——全部改成證物、條件、目標與結局。完整對照寫在 `engine-constraints.md`。
- **名字一字不差**：翻譯稿最常見的問題是同一個人兩種譯名（以西結／依西結、開普勒／凱普勒）。目標與證物靠名字比對，轉換前先統一。
- **不要改編後公開發布作者不允許改編的作品**。學手法，不搬劇情。

## 十、在地化（港台）

### 中式表層、神話底層〔華富邨〕
對港台玩家，「舊公屋＋殭屍片」「紙紮鋪＋鬼節」一點就通，比解釋克蘇魯有效。中式民俗做表層恐怖，神話只放在最底層的真相；在地傳說和神話用**一個元素**接起來（例如：靠海常有人溺水 ↔ 海裡的舊神）。玩家面前只說「海裡的東西」，神話名詞留在給 GM 的真相段。

### 民俗物件同時是機關
寫著生辰八字的木人、門上的八卦、紙紮人、符籙、冥燭——每一件都既是恐怖畫面，也是線索或解法（冥燭快燒完＝看得見的倒數）。

### 港台都能直接用（不用加註）
三魂七魄、生辰八字、頭七、紙紮、線香、八卦、黑白無常、茅山、殭屍、符籙、土地公、鬼月、颱風暴雨天被困在家、「別去水邊」的禁忌、凶宅、合租分租。

### 港版／台版對照
| 港版 | 台版 |
|---|---|
| 公屋屋邨（天井、口字走廊） | 老國宅、老商場（走廊、天橋、樓梯間） |
| 紙紮鋪、茅山師傅 | 糊紙店、師公 |
| 黑白無常 | 七爺八爺 |
| 門口土地 | 地基主 |
| 養鬼仔 | 養小鬼、魔神仔（把小孩帶走的傳說） |
| 七月十四燒衣 | 中元普渡、燒金紙、放水燈 |
| 茶餐廳 | 冰果室 |
| 唐樓、劏房、村屋 | 老公寓、無對外窗套房、透天厝 |
| 天文台暴雨 | 颱風警報、豪雨特報 |

西方模組的在地化方向：獵巫審判 → 清代地方冤案或日治時期命案，教會史 → 縣志或文史工作者手抄本〔活神〕；禁酒令私酒 → 日治酒類專賣下的鄉下私釀米酒〔黑水溪〕；「割髮代首」讓「交出身體的一部分」更好猜〔活神〕。

### 一定要換掉的
- **真實事件與真實地方**：真實的命案剪報、真實的學校、真實的店名與品牌，一律改成虛構。真實的靈異傳說地可以用，但不寫真實門牌與住戶。
- **族群刻板印象**：原作裡「原住民部落是獻祭怪物」「土著薩滿是邪術來源」的設定，**不要對應到台灣原住民或香港原居民**，改成架空的先民聚落、外地術士或被官府剿滅的祕密教派。
- **真實神祇**：民間真的有在拜的神，不要直接拿來當邪神，改用架空稱呼（例如山裡的「阿母」）。
- **時代錯置**：1970 年代的香港沒有黑雨警告、沒有手機。年代物件要查。
- **版權內容**：不寫歌詞、不用真實歌曲當關鍵、不抄經典作品的咒文與段落。音樂改成故事裡的聲音（收音機自己轉台、一首很老的時代曲）。
- **兒童與暴力**：兒童受害只寫事後痕跡，不寫過程。玩家扮演孩子時，危險寫成「被抓住、被困住」，不寫傷害。
- **用語**：介面是台灣繁中；港式背景靠名詞（屋邨、鐵閘、茶餐廳）營造，不用粵語語法。注意台灣口語裡「酒店」有陪侍的聯想，海濱住宿寫「飯店」「旅館」。

## 附：五篇共同的失敗（寫完對照）

1. 決定勝負的知識或工具只有一條路，還壓在一次檢定後面。
2. 觸發條件是「主持人看情況」，沒有寫成回合、地點或證物。
3. 開場有好幾個起點，或一開場整張地圖全開。
4. 有地點沒事做、有 NPC 沒有獨特情報。
5. 照著委託或目標做，反而走向壞結局。
6. 勝利條件寫成結果（「處理掉」「解決」），沒有可以執行的動作。
7. 要玩家猜到特定動作或句子才能前進。
8. 關鍵事件靠「強制某人」「暗中操作擲骰」「只有某人看得見」。
9. 結局靠商量或擲表決定，沒有預先寫好下場。
10. NPC 陣營隨玩家選擇翻轉，高潮建立在翻轉上。
